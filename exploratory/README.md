# Pre-specified exploratory analyses and derived sensitivity tests

None of these analyses enter the preregistered verdicts. Their specification choices are recorded in [`../deviations/DEVIATIONS.md`](../deviations/DEVIATIONS.md) (D4, D5).

| File | What it is | Log entry |
|---|---|---|
| `sensitivity_hypotheses.py` / `.csv` | H1a–H3 tested under each preregistered sensitivity specification, computed from the frozen outputs | D4 |
| `meta_regression.py` / `.csv`, `site_covariates.csv` | Sources of heterogeneity: meta-regression on climatological FMF, mean RH and coast distance | D5 |
| `frh/` | External validation against Burgos et al. (2019) f(RH=85 %): site matching, slopes and correlation | D5 |
